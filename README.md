# Генератор паролей

Настольное приложение на Python (tkinter) для создания случайных паролей
с оценкой их надёжности. Учебная практика УП 02.01 «Осуществление интеграции
программных модулей».

## Возможности

* выбор длины пароля (4–64 символа);
* выбор наборов символов: строчные, заглавные, цифры, спецсимволы;
* гарантированное наличие символа из каждого выбранного набора;
* оценка надёжности по энтропии;
* копирование пароля в буфер обмена.

Пароли создаются модулем `secrets`, который предназначен для криптографических задач.

## Структура проекта

|Файл|Назначение|
|-|-|
|`generator.py`|логика генерации и оценки надёжности|
|`app.py`|графический интерфейс|
|`tests/test\\\_generator.py`|модульные тесты|

## Установка

1. Установить Python 3.9 или новее (tkinter входит в стандартную поставку).
2. Клонировать репозиторий:

```
   git clone https://github.com/<ваш-логин>/password-generator.git
   cd password-generator
   ```

## Запуск

```
python app.py
```

## Сборка

Сборка не требуется. Для получения исполняемого файла можно использовать PyInstaller:

```
pip install pyinstaller
pyinstaller --onefile --windowed app.py
```

## Тестирование

```
python -m unittest discover tests
```

## Документация

Основные функции модуля `generator.py`:

* `generate\\\_password(length, use\\\_lower, use\\\_upper, use\\\_digits, use\\\_symbols)` — возвращает строку-пароль;
* `estimate\\\_strength(password)` — возвращает пару (энтропия в битах, текстовая оценка);
* `PasswordParamsError` — исключение при некорректных параметрах.
